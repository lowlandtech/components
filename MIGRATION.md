# Component history extraction

Source: lowlandtech/foundry develop at c7cb4e12d48173f13dd40bc94c97623372cec4b4.

574 component commits were extracted from components/src/ and src/components/ into src/. Authors, timestamps and commit messages are retained; extracted commit IDs change because paths and trees change.

The previous components repository main and develop histories are retained through an ours-strategy merge. Their old files are not included in the current tree.

The src/ tree exactly matches the source src/components/ tree at extraction. Foundry retains its original component files.

Standalone build integration remains: projects reference Foundry projects outside this repository, and some package icon paths assume the monorepo layout.
