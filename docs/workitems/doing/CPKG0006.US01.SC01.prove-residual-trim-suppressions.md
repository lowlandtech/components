## Completion — 2026-11-04

### UAC03 — the outbox payload now survives trimming

The payload path needed a way for a host to hand over the payload contract, and it is
additive:

- `SessionOutboxEntry` gained an optional `JsonTypeInfo? TypeInfo` member;
- `SessionOutboxList.SerializePayload` writes through that contract when it is present and
  keeps the reflection path — and its `ToString()` fallback — for a host that supplies
  none.

The probe's consumer generates a contract for its own payload type and passes it. The
trimmed run now observes `OUTBOX_VALUE=True` and `OUTBOX_SEVEN=True`, where before it
rendered `Cpkg0006.Consumer.ProbePayload` (the fallback).
