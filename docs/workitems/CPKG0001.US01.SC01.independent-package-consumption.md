The upstream source is now located at
`D:/lowlandtech/develop/src/core/LowlandTech.Core.csproj`. It is packable as
LowlandTech.Core 2026.5.29 and contains the missing Abstractions and Graph.Entities
namespaces. A candidate archive also exists at
`D:/lowlandtech/develop/artifacts/nuget/LowlandTech.Core.2026.5.29.nupkg`.
Use these as upstream evidence, not a permanent absolute ProjectReference.
Inspect and compile the required full API against the selected package before
replacing Components' broken reference. Do not overwrite/rebuild an existing
package version with different bytes.

not declare that dependency. Verify contract/type ownership and a compatible
Components.Core version without circular dependencies or duplicate CLR types.
The package also uses older EF/Extensions and NCalcAsync dependencies than source;
matching version strings do not establish source/binary compatibility.
