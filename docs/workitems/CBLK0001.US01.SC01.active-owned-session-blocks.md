## Outcome

Plugin session block lookup resolves only validated active owned descriptors.

## Implementation boundary

Add an optional bridge for existing ISessionBlockRegistry/ISessionBlockDiscovery contracts. Record owner, node-type key, priority and trusted component mapping. Validate one candidate before publication and preserve host defaults.

## Acceptance criteria

- [ ] UAC01: Given duplicate/conflicting or wrong-type owned descriptors, when the candidate is validated, activation is refused with a named diagnostic and the previously published lookup remains unchanged.
- [ ] UAC02: Given active and inactive plugin descriptors plus host defaults, when GetDescriptors/GetDescriptor/ResolveComponentType are queried, only valid active descriptors participate in deterministic priority resolution.
- [ ] UAC03: Given a plugin component remains in a loaded assembly after withdrawal, when all lookup paths including assembly-scanning fallback are queried again, it cannot reappear as a plugin contribution and host fallback remains available.
