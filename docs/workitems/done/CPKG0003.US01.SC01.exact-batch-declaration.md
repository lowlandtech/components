## Outcome

A batch of this repository declares the contracts generation it was built against
as an exact range instead of a lower bound, and its version sorts above every batch
the feed already holds. A consumer that resolves that batch together with the Core
generation that pins the same contracts therefore resolves one pair and reports no
`NU1608`, and a "latest" resolution cannot pick an older batch.
