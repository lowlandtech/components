## Outcome

The trimmable declaration of `CPKG0007` is honest under the linker, not only under the
Roslyn analyzer: a consumer that publishes trimmed sees no trim warning that names a
components assembly, and the batch that carries the declaration is superseded by one
that does not warn.

## The defect that the verification found

`CPKG0007` annotated `ComponentDescriptor.ComponentType` on the property only. The
trimmed-host probe then reported one warning against the components assembly:

- `IL2069` — the value stored in the descriptor's backing field did not satisfy
  `DynamicallyAccessedMembers(PublicParameterlessConstructor)`, because the record's
  constructor parameter carried no annotation;
- after the constructor parameter was annotated, `IL2062` — the registry passed the
  unannotated type of a loaded assembly to `BuildDescriptor`.

Both were invisible to the Roslyn analyzer of the package build, which reported zero;
the linker reports the same flows with its own codes.

## What changed

| Surface | Change |
|---|---|
| `ComponentDescriptor` | the constructor parameter carries the same `DynamicallyAccessedMembers` requirement as the property |
| `ComponentDescriptorRegistry.BuildDescriptor` | its `type` parameter declares the members the descriptor reads |
| `ComponentDescriptorRegistry.Discover` | the single reflective root suppresses `IL2072` and `IL2062` with the preservation the host owes |

### The measured constraint carried forward

drops the trimmed package assembly from `deps.json` and the host reports a missing
assembly although the file is in the output. The `.NET 10` default (`full`, which the
Builder's wasm project uses because the `partial` default applies only below `.NET 8`)
loads it. The constraint is recorded here and in the consumer notification.
